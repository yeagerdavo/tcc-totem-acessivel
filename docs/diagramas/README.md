# Diagramas

Esta pasta é destinada aos diagramas do projeto.

## Conteúdo esperado
- arquitetura do sistema
- fluxos de funcionamento
- diagramas de componentes
- diagramas de integração
- diagramas de processo
- outros esquemas visuais úteis para entendimento técnico

## Objetivo
Apoiar a documentação técnica e facilitar a visualização da estrutura e do funcionamento do sistema.
